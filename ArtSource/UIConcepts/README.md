# 空间站重启 UI 图片样例

日期：2026-09-16。用途：视觉方向预览，供选择与后续 UI 实现参考。

三张图片使用内置 `image_gen.imagegen` 生成，采用白灰底色、橙色主操作、青蓝供电提示，并参考本项目已有机器人的形体与配色。

| 图片 | 设计重点 |
| --- | --- |
| [主菜单](main_menu.png) | 游戏标题、开始游戏、关卡选择、设置、退出与机器人展示 |
| [游戏内 HUD](gameplay_hud.png) | 关卡目标、供电数量、移动/推动统计、暂停与快捷键 |
| [关卡选择](level_select.png) | 正式三关的预览卡片、当前选择状态与进入按钮 |

## 使用范围

- 这些是 AI 生成的静态概念图，不是 Unity 实机截图，也不是已切分的 UI 素材或已实现界面。
- 场景、角色细节、关卡缩略图和镜头均为示意；缩略图不对应真实关卡布局，装饰不代表新的场景制作要求。
- HUD 的 24 次移动、8 次推动和 1/2 供电为排版示例，不是实测或持久化成绩。
- 选关页的三个正式关卡均可选，橙框表示当前选中，没有加入解锁规则。
- 主菜单的功能来自 GDD 的目标范围；本次没有实现主菜单、设置或进度保存。
- 后续实现时应使用 Unity 文本组件呈现中文和数字，使用已有机器人和真实关卡渲染预览。

## 生成与检查

完整最终提示词保存在 [prompts.json](prompts.json)。提示词基于 `Docs/GameDesign.md`、项目 README、机器人预览与已有游戏截图的人工阅读整理；此次未向工具提供输入图片，输出为新生成图像。

已目视检查三张图的主要中文标签、按钮层级、HUD 留白和三张关卡卡片。工具添加了少量场景装饰文字；它们不作为游戏文案。文件尺寸和 SHA-256 记录在 [manifest.json](manifest.json)。本次只新增概念图及记录，未更改 Unity 资源、代码或项目设置。
