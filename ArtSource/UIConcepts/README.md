# Robot Sokoban UI 图片样例

日期：2026-09-16。用途：视觉方向预览，供选择与后续 UI 实现参考。

游戏正式名称已在 v0.8.2 统一为 **Robot Sokoban**。本目录的概念图和 Prompt JSON 保留生成时的原始标题，作为历史设计证据；当前主菜单使用新名称。

这里的两份Prompt JSON保存图像生成历史及可追溯证据，不是当前Agent执行指令。它们包含已放弃的视觉方案，不应作为新增玩法或场景需求加载；当前界面实现以 [UIImplementation.md](../../Docs/UI/UIImplementation.md) 为准。

## 当前方向：第二版简约 UI

用户反馈首版场景渲染过重、与实际游戏画面不符。第二版收敛为一张 [纯 UI 样式板](minimal_ui_v2.png)：浅色底、深灰文字、细线分隔与少量橙色强调，展示主菜单、HUD、纯文字关卡列表和完成弹窗，不包含场景、机器人或关卡缩略图。

第二版使用内置 `image_gen.imagegen` 生成。初次输出存在背景透明处理异常，随后通过同一工具修正，仓库仅保存修正后的最终图片。[第二版完整提示词](prompts_v2.json)记录两次调用。已目视检查背景、中文标签及组件布局，并核对复制前后 SHA-256。该方向已用真实UGUI控件实现；概念图本身未作为游戏背景，数值仍为排版示例。

## 使用范围

- 这些文件是AI生成的静态概念图，不是Unity实机截图或已切分的UI素材；实际界面及其验证记录见上方实现文档。
- 场景、角色细节、关卡缩略图和镜头均为示意；缩略图不对应真实关卡布局，装饰不代表新的场景制作要求。
- HUD 的 24 次移动、8 次推动和 1/2 供电为排版示例，不是实测或持久化成绩。
- 选关页的三个正式关卡均可选，橙框表示当前选中，没有加入解锁规则。
- 图像生成当时未实现菜单；当前主菜单和设置已实现，关卡进度保存仍待完成。
- 当前采用第二版纯文字关卡列表；首版缩略图与场景插画不是后续实现要求。UI文案和数字使用Unity文本控件呈现。

## 生成与检查

完整最终提示词保存在 [prompts.json](prompts.json)。提示词基于 `Docs/Gameplay/GameDesign.md`、项目 README、机器人预览与已有游戏截图的人工阅读整理；此次未向工具提供输入图片，输出为新生成图像。

已目视检查三张图的主要中文标签、按钮层级、HUD 留白和三张关卡卡片。工具添加了少量场景装饰文字；它们不作为游戏文案。文件尺寸和 SHA-256 记录在 [manifest.json](manifest.json)。本次只新增概念图及记录，未更改 Unity 资源、代码或项目设置。
