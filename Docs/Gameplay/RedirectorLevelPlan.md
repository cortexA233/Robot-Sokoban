# 转向板与六张紧凑运输关卡方案

日期：2026-09-17 · 开发版本：[v0.3.0](../Versions/V0.3.0.md) · 状态：**已实现并验收，v0.3.0 已封版。** 正式落图结果见第 7 节。

本次建议新增“固定转向板”，与供电门、低摩擦轨道组成三条主要机制，追加六关。能源箱和普通箱沿用现有规则，普通箱继续作为让位、挡停和站位调度的工具。这里的“三机制”指**供电门 + 滑动轨道 + 新增转向板**，不把箱型再拆成一条新机制。

- **箱子进入普通地板、插槽或打开的门格都会停止。** 门打开只表示能进入，不会把它变成连续滑轨；箱子停在门上后，需要玩家跟进并再推。
- 供电按每次单格位移重新计算；门保留占据防夹规则。不能设计成“先断电，再靠动画惯性穿过已经关闭的门”。
- 本轮沿用 `v0.2.0` 的插槽/门表现与 `v0.2.1` 保留的 L04–L06；新关追加到其后，原 L01–L03 不恢复。

## 2. 推荐机制：固定转向板

**玩家只需记住一句话：箱子进入箭头格，就沿箭头继续走；挡住出口可以让它停下来。**

它为现有玩法增加“去向”的规划：轨道决定会滑过哪些格子，转向板改变运输方向，供电门决定某条路何时可用。玩家无需新增按键，仍然只推箱。

### 完整规则

1. 板上有固定 N/E/S/W 箭头，方向由关卡作者设置。玩家在游玩中不能旋转它；板本身不需要供电。
2. 能源箱和普通箱进入板格后，当前自动移动方向改为箭头方向，并尝试再走一格。无需先从轨道进入，直接推动入板也生效。
3. 下一格是轨道，沿新的方向继续滑；是另一块板，采用新箭头；是普通地板、插槽或打开的门格，进入后停止。
4. 箭头出口被墙、边界、关闭门、其他箱子或机器人占据时，箱子停在板上。不连推、不反弹，不会穿过机器人。
5. **受阻停稳后，移开挡路物不会让箱子自行重启。** 下一次仍需玩家推动。玩家取得相应发力格后，可以朝任一合法方向推离这块板，离板后的目标格再按上述规则解析。
6. 机器人经过板和轨道都只走一格，不被带走。箱子转弯时，机器人仍停在这次推动的原箱格。
7. 从第一格推动到全部转向、滑行结束，合计一次移动、一次推动、一次撤销；只有稳定终局判定通关。
8. 箭头板只占普通地板，不与插槽、门或轨道叠在同一格。初始放置和 GM 移位到板上都不自动启动。
9. 自动路线出现循环时，整条指令拒绝并恢复原局面，不增加计数；编辑器/调试信息明确提示循环。正式关卡不得依赖循环拒绝作为解谜手段。

第 5 条是本轮最有价值的组合：**普通箱既可以当临时刹车，也可以在完成挡停后让出新的推箱站位。**

### 表现要求

- 转向板用粗箭头、独立轮廓和地面凹槽辨识；轨道继续用连续平行纹理。不能让两者只靠颜色区分。
- 普通轨道的装饰纹理不表达方向；只有转向板箭头决定方向，避免玩家误以为整条轨道都是传送带。
- 箱子压住板时，箭头方向仍能从板边和俯视提示看出；两种箱型、门开关与供电身份继续可读。
- 箱子沿逐格折线播放转弯，不能用直线插值切过墙角。逻辑不等待动画，也不增加操作时机要求。

## 3. 六关安排

六关中前两关是短教学，后四关利用中转与回收空间增加组合约束，允许新机制刚出现时短暂降低难度。下表尺寸与数量已同步正式数据；关卡最初设计职责保留如下，正式参考解法与落图调整见第 7 节。难度仍需独立玩家试玩评估，地图大小和解法步数不代替难度结论。

“电 / 货”分别表示能源箱与普通箱；“目 / 辅 / 门 / 板”分别表示目标插槽、辅助插槽、受电门、转向板数量。

| 建议 ID / 名称 | 建议尺寸 | 电 / 货 | 目 / 辅 / 门 / 板 | 核心问题 |
| --- | --- | --- | --- | --- |
| L07 · 拐个弯 | 7×7 | 1 / 0 | 1 / 0 / 0 / 1 | 箱子能转弯，但机器人必须自己绕到下一个发力格 |
| L08 · 借箱刹车 | 7×7 | 1 / 1 | 1 / 0 / 0 / 1 | 障碍箱要先保留，挡停能源箱后再移走 |
| L09 · 借电发车 | 8×8 | 2 / 0 | 2 / 1 / 1 / 1 | 临时供电、门格停靠、深处目标接替供电 |
| L10 · 共用转角 | 8×9 | 2 / 1 | 2 / 1 / 1 / 1 | 两路进料共用转角与中转位，先完成哪一个 |
| L11 · 刹车要回来 | 9×9 | 2 / 1 | 2 / 0 / 1 / 2 | 同一只普通箱在两个区域挡停，需要保留跨区回收路线 |
| L12 · 最后一班 | 9×9 | 2 / 2 | 2 / 1 / 2 / 2 | 发车、中转、交付三区的供电、挡停和回收依赖 |

所有能源箱等价；下面的 A/B、a/b 只用于讲解，不要求指定箱子匹配指定目标。

### L07 · 拐个弯

- **结构**：左下发车井、上方直角运输段、右侧接货井，底部是一格宽的机器人绕行路。
- **关键过程**：机器人绕到箱子下方 → 向北发车 → 箱子转向东并停在普通地板 → 机器人从底部绕至右侧 → 向北推进目标。
- **教学重点**：进入普通地板就停、箱子会转弯、机器人不跟车；先只教这些，不叠供电。
- **提示**：“箱子会自己拐弯，你需要走到它后面。”
- 已有可回放的 7×7 教学草案，见第 4 节。它是短引导关，不用增加无意义搬运来追平 L06 的推动数。

### L08 · 借箱刹车

- **结构**：水平进料轨道终点是一块向北转向板；北侧普通箱堵住出口，真正目标位于板南侧。
- **关键过程**：保留普通箱 → 能源箱滑入板并被挡停 → 把普通箱向东推入永久侧袋 → 机器人取得板北侧站位 → 将能源箱向南推入目标。
- **新的理解**：挡路箱有用；移开挡路物不会让已经停稳的箱子继续跑。
- **错误计划**：先把普通箱清走，能源箱会被送进无法从北侧接近的上方区域。
- **提示**：“先让它停稳，再清理出口。”已有完整教学草案与离线顺序检查。

### L09 · 借电发车

- **结构**：一个辅助插槽 s 控制运输出口门 D，门后是先深后浅的两个目标 a/b；转向轨道负责把箱子送到门前或门格。
- **8×8 空间用途**：分开辅助电源侧袋、门前停靠区与机器人回程路，保证停在门格的箱子有可达的再次发力位。回程路需要检查，避免能源箱直接绕过门和运输段。
- **供电连接**：`D = Any(s, a)`；浅处目标 b 不供这扇门。
- **预期依赖**：B 先上 s → A 发车并停在门格 → 玩家从预留通道到箱子后方，再把 A 送入深处 a → a 接替供电 → 回收 B 并送到 b。
- **新增理解**：运输过程中的供电必须持续；门是一个需要再次发车的停靠点。
- **布局验收**：断开 s 后应失去第一批运输能力；去掉门不能只减少一次无关紧要的步行。保持合法占门保开的替代解，不强迫唯一剧本。
- **提示**：“先送到另一侧的能源，可以接替临时电源。”

### L10 · 共用转角

- **结构**：两个进料区汇入同一块转向板和出口；浅处目标会占用运输或换手站位，普通箱占着唯一临时侧袋。与 L09 的单向纵深通道使用不同墙体骨架。
- **8×9 空间用途**：容纳两处候车位、一处共用中转位和一条换侧绕行路。让玩家能选择先处理哪只箱子，再由中转位的占用和目标深浅约束发车顺序。
- **供电连接**：`D = Any(s, a)`，沿用已经学会的交接关系。
- **预期依赖**：暂存第一只能源箱 → 普通箱让出侧袋/换手格 → 先把另一只送到深处 a → 回收暂存箱 → 最后完成浅处 b。
- **核心区别**：玩家需要规划“哪只先发车、哪只暂存”，目标位置最近的箱子未必最先归位。
- **布局验收**：普通箱必须改变某个必要站位；暂存箱必须能够回收。不能只是复刻 L05/L06 再铺几块轨道。
- **提示**：“别先占住下一班还要经过的位置。”

### L11 · 刹车要回来

- **结构**：两段方向不同的运输线、两块转向板和一个可回收的普通箱停车区。中央通道容纳换侧站位，不增加第三只能源箱。
- **9×9 空间用途**：把两次挡停放在两个相邻区域，中间用带 2×2 换侧区的回收通道连接。第一次停靠时要同时考虑第二次搬运的出口和发力方向，让 X 的位置连续影响两段谜题。
- **供电连接**：正式落图采用 `D = Any(a)`；首个目标完成后开放第二段运输，不设置辅助插槽。
- **预期依赖**：X 在第一处挡停 A → A 换侧进入第一目标 a → 从可回收侧袋取回 X → X 到第二处挡停 → B 利用第二次停靠进入 b。
- **核心区别**：L08 的普通箱可以永久丢进侧袋，这次必须保留再次推动所需的站位。
- **布局验收**：固定 X、提前把 X 推入永久角落、只使用一次挡停分别检查；每一处回收都要标出机器人从哪一侧发力。避免用第二条线简单复刻第一条线。
- **提示**：“这只箱子还要再当一次刹车。”

### L12 · 最后一班

- **结构**：发车区、中央中转区、目标交付区构成三个互相依赖的区域；X 负责可回收挡停，Y 负责让出首箱发车的推动站位。两个门承担不同职责，一个控制发车通路，一个控制后期回收/换侧通路。
- **9×9 空间用途**：容纳目标完成后才可用的跨区回程路，以及兼任临时停车位的换侧区。首个目标点亮前后，玩家要重新安排同一片空间的用途；仍以两能源箱、两普通箱形成依赖。
- **供电连接建议**：`D1 = Any(s, a)`，`D2 = Any(a)`。首次临时供电只能使用第一条路；a 点亮后，第二条路才加入解题。
- **预期依赖**：B 初始占据 s → Y 让出首箱发车站位 → X 安排第一次停靠 → A 经过转向与门格接力，送入 a → a 同时维持 D1 并开启 D2 → 利用新路回收 X、改作第二处挡停 → 回收 B 完成 b。
- **核心区别**：第一个目标不仅是交付点，也会改变后半局的可达站位；普通箱一个可永久停放，一个必须回收，职责明确。
- **布局验收**：两扇门必须各自影响一个必要阶段；不能只为增加数量设置。先在 9×9 上限内安排完整的回收与换侧站位；若仍容纳不下，再调整分区或简化一层调度依赖。新增绕行路要检查是否让箱子绕过关键机关，已有门规则保持一致。
- **提示**：“先完成的那个目标，会给你打开回收路线。”

### 第一步：一个机制贯通制作链

| [LevelDefinition](../../Assets/Scripts/Gameplay/Domain/LevelDefinition.cs) / [LevelJson](../../Assets/Scripts/Gameplay/LevelFlow/LevelJson.cs) | 建议新增带稳定 ID、坐标、朝向的 `RedirectorDefinition[] redirectors`，置于 Floor；新内容写 schema v3，旧 v1/v2 显式补空数组。维持旧版本线格式与哈希策略，不能顺手让旧解法全部失效 |

| 表现 | 可读箭头、被箱子占据时的方向提示、逐格转弯动画；沿用占门保开与供电状态显示契约，不覆盖 v0.2.0 的工作 |

### 第二步：白盒逐关制作

1. L07/L08 正式内核复核后，再制作 L09，把门格停靠和供电交接验证清楚。
2. L10/L11 先确认可回收停车位与玩家绕行路线，最后组合 L12。
3. 每个关键推动记录：箱子起点、终点、机器人发力格、停止原因、当时的电源与可达区域。
4. 每只普通箱记录：第一次用途、停放点、是否需要回收、回收站位；避免无意义占格和仅延长运输。
5. 参考解法可以不唯一；检查占门、换箱、挡停等合法变体，不能为排除聪明解法而临时改规则。
6. 每关记录最终宽高，均不超过 9 格；为新增绕行和暂存区域写明用途，检查它们是否改变运输顺序、停点或能源回收，同时检查是否消除了预期的关键约束。

### 第三步：规则与实际游玩验收

- 规则：两类箱子从四方向入板、正向/反向入板、连续板、板接轨道、轨道接板、玩家阻挡、出口封闭、受阻后不自动重启、重新推动离板、循环整条拒绝。
- 供电：离槽立即断电；开门格停靠；占门保开；目标/辅助供电交接；只在整条动作结束时判断完成。
- 状态与表现：多次转向合计一次推动/撤销；转弯中 Z/R、暂停、切关与视角切换；动画不斜穿墙，恢复不残留旧供电或箱子位置。
- 作者工具：旧数据与解法兼容、新格式往返、非法摆放定位、方向修改导致解法失效、制作→保存→打开→试玩→回放全流程。
- 关卡：保留三关和 LAB01 回归；新六关正式参考解法回放；选关与连续游玩；双视角观察轨道、板箭头、箱型和窄门，覆盖 9×9 全图取景与局部换侧区的可读性。
- 调难度：记录第一次误判、撤销原因、是否读懂停车位置和普通箱回收。推动次数或离线可解不替代难度实测；本阶段不预设未经测试的通关时长。

机制的必要性要看它是否改变路线、停点或操作顺序。用“移除普通箱 / 固定普通箱 / 断开电源 / 替换转向板 / 把轨道改成地板”等变体比较，不统一要求所有变体无解：部分移除会放宽约束，改变的是谜题内容。

## 6. 控制为四关或五关的备选

- **六关推荐版**：采用全表，保留两段短教学和四种组合问题。
- **五关版**：省去 L10「共用转角」，在 L11 保留清楚的回收提示，再进入 L12。
- **四关版**：保留 L07、L08、L09、L12 的设计职责；末关缩为两能源箱、一普通箱、一门的综合版，减少一层挡停回收依赖，避免从 L09 直接跳入完整末关。

缩减关数时，末关仍可使用 9×9 以保留必要的换侧和回收空间。关卡 ID 为建议预留，正式制作前再次确认未被占用；采用缩减方案也不重编号已有 L04–L06。推荐先按六关方案做白盒，依据实际试玩决定是否采用缩减方案。
