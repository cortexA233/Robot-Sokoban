# v0.11.0 · Blender 美术细化实验

状态：已完成

实施起始提交：`786a08e`（v0.10.1，先登记计划后开工）

实验分支：`codex/experiment-art-polish`（当前目录，不创建独立工作树）

## 目标与范围

- 基于 v0.10.1，通过 Blender MCP 维护现有可编辑源文件，细化机器人、能源箱、普通箱、受电门、插槽，以及转向板/低摩擦地面；在 Unity 中统一材质与灯光表现。
- 保持简洁工业科幻风格，强化装配层次、功能面板和材质区分。细节同时服务于默认俯视和第三人称。
- 用户明确排除悬空平台收边；不修改普通地板外轮廓、平台底部、墙体、星空、关卡布局与游戏规则。保留资源 GUID、机器人尺寸/接触面/Idle-Move-Push 动画及门四向通行。
- 不覆盖 `test111` 等原有工作；不合并、推送或发布实验分支。
- 细化几何预算：机器人沿用 10,000 三角面上限；能源箱 6,500、普通箱 4,500、门 6,000、插槽各 3,500、新转向板 1,000、低摩擦地面 1,200。静态细节并入原 Renderer，新增材质/贴图共享。

## 验收计划

- 备份现有 Blender 源文件及导出文件，通过源数据与 FBX 回读核对尺寸、节点、材质角色和动画。
- Unity 导入与编译、Console、模型/材质/Prefab 引用及受影响的资产/机关/相机 PlayMode 检查。
- 实机检查俯视、第三人称、机关供电/门开合、机器人推动与双分辨率；对比同机位基线。
- Windows 构建及启动检查，确认资产与渲染表现进入 Player；检查受保护文件哈希和聚焦 Git 差异。

## 执行结果与限制

- Blender 5.2.2 LTS + MCP 完成现有源文件增量制作，原源文件已备份。机器人增加检修面板、头部接缝、接口、轮毂与推杆套筒；两类箱子增加锁扣/加强结构；门增加导轨、驱动罩与顶盖细节；插槽增加可见金属座和触点。
- 新增 RedirectorPlate 与 LowFrictionDeck 的 Blender 源模型、FBX、Prefab；运行时保留箭头/边缘方向提示，显示插槽物理底座并沿用既有供电与连接语义。普通地板与墙体 FBX 未改，没有平台收边。
- 五张共享金属度/光滑度纹理及一张微表面法线（均为 256²）；游戏相机增加 SMAA、轻微 Bloom、Neutral 色调映射和关卡所属补光，不改变全局天空盒/环境光设置。
