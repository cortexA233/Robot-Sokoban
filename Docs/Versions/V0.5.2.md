## 执行结果与限制

- 已按“已规划 → 进行中 → 已完成”完成静态检查与文档维护；本轮未修改运行时代码或 UI Prefab。
- 用户观察：主菜单、暂停菜单等处鼠标移入按钮后闪烁一下；用户提出选中态和悬停态换色可能有问题。根因尚未确认。
- 静态核对：[按钮生成器](../../Assets/Scripts/Editor/UI/StationUIAssetBuilder.cs) 为悬停与选中配置了不同颜色，渐变为 0.12 秒；[MainMenu](../../Assets/Resources/UI_prefabs/screens/MainMenu.prefab) 的 4 个按钮和 [Pause](../../Assets/Resources/UI_prefabs/screens/Pause.prefab) 的 5 个按钮均保留这组配置。次要按钮常态背景透明，主按钮常态为橙色；没有在本轮更改颜色。
- 焦点入口：[StationPage.Present/FocusFirst](../../Assets/Scripts/UI/StationPage.cs) 在非 HUD 页面打开且可交互时调用 FocusFirst，首个 Selectable 可交互且存在 EventSystem 才选中；[StationUIController.Transition](../../Assets/Scripts/UI/StationUIController.cs) 在转场开始清空焦点，结束后对可见的非 HUD 页面调用 FocusFirst。本地 UGUI `Selectable.currentSelectionState` 的判定顺序为禁用→按下→选中→悬停→常态；鼠标移入本身更新指针状态，并不自动选择按钮。以上只能说明需检查的状态路径，不能证明配色差异就是本次闪烁根因。
- 覆盖边界：[StationUITests.Click](../../Assets/Scripts/Tests/PlayMode/StationUITests.cs) 虽先执行 EventSystem 射线检查，但之后仅派发 PointerClick，未驱动移入/移出/按下/抬起的完整序列，也未逐帧检查渲染颜色；已有点击流程通过不能作为“无悬停闪烁”的证据。
- 已在 v0.6.0 / R01 增加复现、事件/焦点/颜色记录、针对性回归，以及 Editor/Player 下鼠标与键盘交接、页面往返和持续悬停的验收要求；同步台账与文档索引，并修正路线图末段仍将 v0.5.0 写为下一版本的旧描述。
