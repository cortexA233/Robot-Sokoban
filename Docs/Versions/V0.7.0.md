# v0.7.0 · 简单音效、BGM 与操作反馈

状态：已规划 · 类型：音频 / 操作反馈 · 需求：R08 · 策划起始提交：`2a13adb` · 实施起始提交：待开工时记录。

## 目标与范围

- 排期前置：[v0.6.0](V0.6.0.md)。落实用户明确要求的简单关卡音效和简单 BGM，保持低干扰、小规模；共用设置页风格与现有动作、供电、导航状态。
- 基础音效覆盖移动/推动、受阻、落位、通电/断电、完成和 UI 点击。根据真实事件触发，限制重复受阻及密集机关变化的叠播，音乐或音效不驱动玩法逻辑。
- 首轮接入 **一首关卡共用、可循环的简单 BGM**。默认同曲切关和重开保持连续，暂停降低音乐音量并停止动作音效，暂停菜单点击音仍可用；恢复后回到用户音量，返回主菜单淡出，退出会话清理。作者试玩使用相同播放规则，退出试玩不遗留声音对象。
- 保留主音量，新增音乐与音效独立音量，零音量可静音；调整立即生效并在重启后恢复，兼容现有设置。新增控件由本版完整实现并沿用 v0.6.0 样式。
- 受阻与完成提供最小的简短图形反馈，复用现有角色锚点与相机朝向逻辑；音画反馈在撤销、重开、切关后不得延迟触发旧事件。
- 开工时细化音色、音乐风格、素材来源、循环接缝和默认混音。使用可随项目分发的现有或原创简单素材，记录来源与导入设置；正式构建需含音频资源及其 `.meta`，不能只在 Editor 有声。
- 不包含每关专属音乐、动态分层配乐、配音、大量特效或机器人动画重做。若改变默认曲目数或暂停/跨关播放规则，在本版本内明确更新计划。

## 验收计划

1. Unity 编译和 Console 检查；对动作取消、连续触发、暂停、重开、切关、会话销毁、设置兼容和保存运行针对性检查。
2. 在实际关卡与独立 Player 中试听全部音效；连续播放 BGM 至少两个完整循环，确认无明显接缝、爆音、叠播或缺失。记录素材、实际音量与试听环境，播放状态断言不代替试听。
3. 连续执行开始/重开/下一关/选关/返回菜单/再进入，确认只有预期的音乐实例，同曲跨关连续，返回菜单淡出；暂停、恢复和作者试玩退出符合约定。
4. 分别调整主音量、音乐和音效到零/中间值，重启独立 Player 检查保存；关闭音乐不影响音效，关闭音效不影响音乐，静音仍能理解稳定状态。
5. 检查长按受阻节流，以及推动/滑行动作中撤销、重开后无旧声音、旧气泡或重复完成反馈；双视角下图形反馈正常，规则和计数不变。
6. 检查音频资源引用、素材来源、构建打包、文档与差异，更新台账并创建 `[v0.7.0]` 聚焦提交。
