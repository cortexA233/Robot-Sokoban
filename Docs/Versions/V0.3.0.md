## 验收计划

本次方案检查：

1. 从正式数据核对 L04–L06 的尺寸、两类箱子、轨道、门停靠和占门保开规则。
2. 完整描述转向后的继续滑行、受阻停留、玩家占格、再次推动、整次撤销和循环处理，避免关卡依赖隐藏规则。
3. 六关分别明确尺寸、箱子/机关预算、关键解题依赖和防绕过检查；教学草案只作为离线模型的设计证据。
4. 检查方案本地链接、草案 JSON、支持脚本与差异；只提交本次文件及版本登记。

后续实施验收：

1. 共享规则、v1/v2 兼容、新数据往返、作者工具完整制作流程及 GM 现场恢复通过。
2. 六关通过正式内核参考解法回放；规则单测覆盖转向与轨道/供电/占据/循环的交互。
3. 等 Unity 编译结束并检查 Console，完成相关 EditMode/PlayMode、双视角与中途撤销/重开检查。
4. 每关审查机制必要性、可恢复错误、普通箱用途与实际难度；通过后才加入正式目录并验证连续游玩。
