# v0.5.0 · 第三人称镜头与场景可读性

状态：已规划 · 类型：镜头 / 场景美术 · 需求：R04、R03 · 策划起始提交：`2a13adb` · 实施起始提交：待开工时记录。

## 目标与范围

- 排期前置：[v0.4.0](V0.4.0.md)。本版先落实默认俯视与 V 键双向切换、改善第三人称观察，再在稳定的双视角机位下完成场景去文字与连接配色，两项共同验收。
- **R04 用户追加：进入关卡默认使用俯视镜头，按 V 切换到第三人称，再按 V 返回俯视。** 默认俯视沿用固定北向的正交镜头，初始居中并完整显示棋盘；第三人称保留鼠标环绕观察。覆盖开始游戏、选关、下一关和编辑器试玩入口。
- V 切换保持同一局面、步数/推动数和撤销历史；移动、推箱或滑行中的命令继续执行，方向与终点不变，清掉尚未开始的移动输入，新模式需重新按下移动键。俯视释放鼠标并支持点击 HUD，第三人称锁定鼠标以环绕观察，暂停时释放鼠标。
- R04：在同一地图与操作路径比较镜头调参、镜头配合较低墙体/门框、镜头配合局部遮挡淡出/隐藏；确定并实现适合当前小地图的方案。检查距离、俯角、FOV、跟随目标、阻尼、避障层及墙体碰撞盒。
- 墙体视觉或镜头碰撞调整保持逻辑格子的不可通行性；先保持格长、地图布局及角色尺寸，保留第三人称环绕、俯视全图和原输入映射。确需局部重做模型时再走现有资产流程，保护源文件与 GUID。
- R03：删除插头和目标旁常驻提示文字，以材质颜色加简洁图形表达门与插槽连接；目标环/插头可组合。处理一门多源、一源多门、Any/All，分别表达连接身份、供电与实际开门状态。
- 连接色断电后保留；能源箱不按门配色；箱子覆盖插槽后仍有可见的目标与连接提示。颜色、形状和状态在表现重建后保持一致。
- 开工时细化第三人称体验取向与 A/B 路径、墙体方案、配色单位、调色板、图形、门旁条件文字和连线的呈现；默认俯视与 V 键双向切换已确定。候选比较包含在本版内，只交付方案对比不能标记完成。
- 不包含重做全部美术、扩大关卡、修改解法规则、UI 页面改版、音频或引擎升级。最终采纳的视觉契约同步当前设计文档，历史验收不改写。

## 验收计划

1. Unity 编译和 Console 检查；运行受影响的场景状态、连接、相机/输入及动作取消检查，确认正式关卡参考解法不因表现改动而改变。
2. 从开始游戏、选关、下一关及编辑器试玩进入关卡，确认初始为固定北向、全图可见的俯视镜头；按 V 进入第三人称，再按 V 返回俯视。连续切换、移动/推箱/滑行中切换均不重载关卡或改写局面、计数与撤销历史；进行中的命令方向/终点不变，旧的待执行输入已清除。检查鼠标锁定/释放、环绕、HUD 点击及视角提示与实际模式一致。
3. 记录窄门、贴墙、转角、边界和推箱路径前后对比，检查穿模、突然拉近、遮挡与下一操作格可见性；覆盖 360° 环绕、长按方向锁定、动作中切镜头、暂停、撤销/重开。
4. 在 720p/1080p、双视角和远近机位检查无常驻插头/目标文字的识别；灰阶及箱子占据时仍能辨认职责、连接、状态。覆盖 Any/All、一源多门、多路交接、普通箱占槽和断电占据保开。
5. 运行受影响的实际 Player 视觉检查；若改了模型、材质或 Shader，补相应导入/构建证据。记录实际参数、图像及剩余体验限制，自动测试不代替画面检查。
6. 同步 GDD 第 0.1/3 节及 UI 操作说明中的默认视角与切换约定，审查差异、文档、源文件与 GUID，更新台账并创建 `[v0.5.0]` 聚焦提交。
