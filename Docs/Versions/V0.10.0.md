# v0.10.0 · 墙体虚空实验

状态：已完成

## 目标与范围

- 从当前 `main` 的关卡表现基线实验：所有 Wall 格按虚空显示，跳过墙体、墙下地板与墙体镜头碰撞，观察第三人称视野和避障距离。
- 统一作用于正式关卡、作者试玩和重建棋盘。保留源关卡的 Wall 数据、不可通行规则、箱子挡停、门和全部机关；不改关卡哈希、参考解法或存档身份。
- 仅实验场景表现，不加入跌落机制、护栏、新美术或镜头参数调整，不合并回 main、不发布。未跟踪的 `test111.json` 及其 `.meta` 保持原样。
- 依赖当前 main 的 BoardView、StationKit、Cinemachine 2.x 与规则内核；独立体验实验按台账规则分配 v0.10.0，不恢复已取消的 v0.9.0。

## 验收计划

- Unity 导入、编译和 Console 错误检查。
- 相关 PlayMode 回归：正式关卡与作者试玩均无墙、墙下地板或墙体镜头碰撞；双视角、完整环绕、门表现、重开/切关正常；规则和关卡数据不变。
- 相关 EditMode 回归与当前正式目录参考解法验证，检查玩家/箱子仍不能进入原墙格。
- 同镜头条件保存前后截图并检查第三人称效果，保留俯视检查；记录实际效果和工具边界，不把主观舒适度当成自动测试结论。
- 检查受保护数据、文档链接和最终 Git 差异，仅提交实验范围。
