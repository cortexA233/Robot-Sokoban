# v0.2.0 · 插槽与受电门可读性

状态：已完成 · 类型：视觉表现 · 起始提交：`027c07b`。先登记为已规划，核对工程与依赖后开始实现；验收时保留已提交的并行 v0.2.1/v0.3.0 变更。

## 目标与范围

- 更新 [视觉方案](../Art/VisualReadabilityReview.md)，采用用户确认的修正版：插头专指门的电源来源；圆环代表通关目标。因此 S 为插头、A 为插头加目标环、B 仅目标环。
- 将确认的简约效果落地到 Unity 正式表现：干净功能格、目标角标、稳定门编号、独立供电状态、断电虚线/通电实线、门的 Any/All 标牌及清晰开关地标。
- 为俯视安排正向、可读的标签，兼顾跟随镜头与箱子占据；继续支持多来源、一源多门、普通箱、撤销/重开和现场重建。
- 保留现有主体模型、Blender/FBX 与机械门动画。不改变逻辑规则、关卡配方、解法、相机控制、引擎或包版本；不发布。

## 验收计划

1. 等待 Unity 导入/编译并检查 Console。
2. 覆盖目标/门电源的组合、无门目标不出现插头、不连 B、Any/All 各来源状态、一源多门、墙体绕线及稳定编号。
3. 验证能源箱/普通箱占槽、占门保开、撤销/重开、暂停、相机切换与销毁重建；运行相关 PlayMode 测试及正式关卡参考解法回归。
4. 在当前正式 L06 及独立 S/A/B 对比测试局面实机截图，检查 1080p/720p、俯视全图/放大及跟随视角；标牌清楚、没有穿墙线或图标遮挡导致的身份丢失。并行 v0.2.1 已移除 L01–L03，原审查截图保留为历史，测试不重新加入这些正式资源。
5. 检查文档链接、差异和无关工作保留；聚焦提交使用 `[v0.2.0]`。
