# v0.4.0 · 编辑器易用性与制作发布流程

状态：已完成 · 类型：编辑器 / 作者工具 · 需求：R02、R05 · 策划起始提交：`2a13adb` · 实施起始提交：`cb88099`（2026-09-17，用户确认按当前计划开始）。

## 目标与范围

- R02：顶栏按文件、编辑、校验与试玩、目录与帮助分组；现场编辑和示例关卡可折叠。画笔分为工具、地形、角色与箱子、机关，常用按钮保持直接可达，提供用途提示。
- 选择模式下点击另一格，同步更新格高亮、格内对象和属性；空格清除旧对象，叠放时默认玩家/箱子优先。同格对象使用可读名称和选中标记，包含玩家；重复点击同格保留当前对象。右侧选择对象会退出放置模式，Esc 回到选择；纯选择不修改文档或产生编辑撤销。二维符号同时呈现箱子和下层机关。
- 试玩按钮对当前工作副本执行校验，直接展示最新完整问题。有错误阻止试玩，只有提示仍可试玩；右侧临时提示约 6 秒后消失，也可关闭，底部问题列表保留并支持坐标定位。编辑后旧结果失效，下一次校验或试玩重新检查。
- R05：独立目录窗口支持加入、移出、排序、撤销/重做、保存，显示结构和当前参考解法状态；正式游戏选关与下一关使用同一目录。移出保留源文件，开发测试关须显式加入。
- 构建前自动检查目录缺失/空目录、缺失或坏 JSON、重复 ID、结构错误，以及缺失、过期或回放不正确的参考解法；同时检查 Bootstrap、玩家、正式 UI 和空间站主题必需资源。窗口与构建回调共用校验服务。
- 保留原有规则、关卡 ID/布局、保存、草稿、旧数据和现场编辑流程。本轮另修复验收发现的地形拖刷重做丢失，以及退出试玩时页面 GameObject 先销毁造成的清理异常。
- 不包含新机关、玩家 UI 美化、镜头/美术、存档、音频、Resources 打包内容筛选；Unity 2022.3.51f1、URP 14、Cinemachine 2.x、MCP 10.2.0 保持不变。

## 验收计划

1. 等待 Unity 编译完成并检查 Console；运行作者数据、保存/复制/恢复、选择和校验、目录、参考解法、现场往返相关 EditMode 测试及受影响 PlayMode 测试。
2. 实际窗口中从空白图放置两类箱子、两类插槽、门、轨道和转向板；检查来源/方向、跨格和同格选择、空格、非法试玩、错误定位、拖刷撤销/重做、保存重开、试玩录制返回。
3. 通过目录 UI 加入、排序、保存、移出，并在游戏选关页核对顺序；检查文件保留。隔离测试坏目录确实被自动构建回调拦下，合法目录能够构建。
4. 核对差异、资源 GUID、文档链接和用户工作保护；更新台账与作者指南，创建 `[v0.4.0]` 聚焦提交。
