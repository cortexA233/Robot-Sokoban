# v0.4.0 · 编辑器易用性与制作发布流程

状态：已规划 · 类型：编辑器 / 作者工具 · 需求：R02、R05 · 策划起始提交：`2a13adb` · 实施起始提交：待开工时记录。

## 目标与范围

- 本版是 [路线图](Roadmap.md) 的第一执行版本，基于现有 v0.3.0 玩法及已提交工具。先整理作者操作，再补齐目录管理，交付完整的“制作→校验→试玩→加入正式目录”路径。
- R02：整理文件/编辑/校验试玩/目录/现场编辑/帮助入口；细分地形、角色与箱子、机关及其现有种类；明确当前画笔、擦除层、朝向、选中对象和未保存状态，按对象显示相关属性。
- R05：提供目录加入、移出与排序，显示关卡结构和参考解法状态；构建前校验正式目录引用、重复 ID 与参考解法是否对应当前内容，错误可定位，不能悄悄跳过坏关卡。
- 同步作者指南；保留 Undo/Redo、原子保存、草稿恢复、旧数据兼容、试玩录制及现场编辑往返。目录移出不删除关卡文件，另存副本以新 ID 重新建立解法证明。
- 开工时细化分类树、控件布局、搜索或快捷入口、目录面板形式；先用现有制作任务比较操作步骤，再落实 UI。常用功能不应因分类细化而变得更难到达。
- 不包含新机关或箱型、玩家 UI 美化、镜头/美术、存档和音频；保留现有正式关卡 ID 与布局。引擎与包版本保持项目约定。

## 验收计划

1. Unity 编译通过，检查 Console；按改动运行作者数据、目录、复制/保存/恢复、参考解法相关 EditMode 检查及试玩桥接的 PlayMode 检查。
2. 从实际编辑器 UI 新建小图，放置两类箱子、两类插槽、门、轨道和转向板，配置来源/方向，完成校验定位、撤销/重做、保存重开和试玩返回；检查现场草稿与正式作者文档隔离。
3. 从 UI 录制或校验解法，加入/排序/移出目录，确认游戏选关随目录变化。隔离验证缺失资源、重复 ID、无效或过期解法确实阻止不合格构建；合法目录可通过。
4. 逐项记录本版覆盖的编辑器要求和实际操作证据，保护原有关卡、解法与草稿；发现本版造成的失败先修复复验，不能留到 v0.9.0。
5. 检查差异、资源 GUID、文档链接与无关工作，更新台账并创建 `[v0.4.0]` 聚焦提交。
