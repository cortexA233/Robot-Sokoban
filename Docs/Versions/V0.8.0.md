## 目标与范围

- 排期前置：[v0.7.1](V0.7.1.md)，使用 v0.5.0–v0.7.0 的镜头、图形、文案和声音，以及 v0.7.1 的入口/门标牌/单色插槽边框修正来解释玩法，避免教学制作后随表现变化重写。
- 复核从现有首关 L04 开始的首次接触：两类箱子、目标与供电、多源门、轨道与转向板、撤销及双视角。L07/L08 的现有转向教学保留为基线。
- 通过 v0.6.0 的帮助入口提供简短、按需查看的通用操作与规则说明，并补必要的首次提示；使用实际操作与图形，避免重新把长文字常驻在目标或插头旁。以 v0.6.0 移除三项逐关文案后的 UI 为基线，不恢复 `title`、`briefing`、`completionText` 配置或对应显示控件。
- 复核九关的信息与难度递进，记录误解、卡点和目标机制使用情况；有证据表明需要时做有限的文案、提示、目录顺序或布局调整，改动同步配方和参考解法。
- 开工时细化教学触发/关闭方式、试玩脚本及难度调整依据。独立玩家反馈单独记录；没有独立参与者时说明限制，不把 Agent 操作或自动解法当作人类难度验证。
- 不预设恢复已删除的 L01–L03，不批量新增关卡，不增加机制或更改胜利规则。新增教学关如确有必要，先明确其范围和验收再纳入本版本。

## 验收计划

1. Unity 编译与 Console 检查；对帮助/提示显示、输入占用、重开/返回、视角切换及提示重复出现的行为运行针对性检查。
2. 从新玩家状态走通首次游玩，记录规则说明的到达路径及实际误解；720p/1080p 检查可读性和遮挡，确认帮助能关闭、不打断未完成动作，不重新引入场景常驻说明堆积。
3. 若修改关卡或排序，使用 v0.4.0 工具流程保存和校验，更新解法证明并复验全部正式关卡参考解法、选关与进度关联；未改动的关卡保持 ID 与原数据。
4. 记录实际试玩依据、独立反馈有无及无法确认的难度结论；审查文档/资源差异，更新台账并创建 `[v0.8.0]` 聚焦提交。
