# v0.10.1 · 虚空场景程序化太空背景

状态：已完成

实施起始提交：`9162293`（v0.10.0）

实验分支：`codex/experiment-wall-void`

## 目标与范围

- 在 v0.10.0 的悬空棋盘实验上，按用户要求由 Agent 选择并实现背景方案。采用程序化星空：深蓝紫色渐变、稀疏静态星点和低对比星云，支持第三人称全环绕及俯视。
- 使用 Unity 2022.3.51f1 / URP 14 的相机独立 Skybox 材质，不改变场景环境光、反射、原模型材质或镜头参数。无外部服务、图片纹理或新包依赖。
- 保留当前关卡、虚空边界、机关、作者草稿与未跟踪的 test111；不合并或推送实验分支。

## 验收计划

- Unity 脚本与 Shader 编译、Console、资源依赖检查。
- 现有相机 PlayMode 回归：切关/重开、V 键、环绕、相机独立背景绑定和全局天空盒不被修改。
- 实机检查第三人称、俯视、不同朝向和 720p/1080p，确认无接缝、粉色错误或背景遮挡棋盘。
- Windows Player 构建验证 Shader/材质实际随游戏进入构建；检查受保护数据、文档链接与聚焦差异，提交本次迭代。

## 执行结果与限制

- 已实现 [SpaceBackground.shader](../../Assets/Shaders/Environment/SpaceBackground.shader)。Shader 以归一化三维方向计算四层噪声星云与两层稀疏星点，不依赖图片、经纬度 UV 或时间；没有时间驱动的闪烁或滚动动画。三维函数跨天空盒面连续，下半球同样具有星云层次。
- 游戏 Camera 的 `Skybox` 组件引用 `StationKitTheme.spaceBackground`，材质为 `Assets/Material/StationGameplay/M_SpaceBackground.mat`。通过已有 Resources 主题资产保留构建依赖；相机销毁时组件随之释放，不克隆材质，不写入全局 `RenderSettings.skybox`，不参与碰撞。
- 材质可在 Inspector 调整，默认值与 Shader 一致：

| 属性 | 用途 | 默认值 |
| --- | --- | --- |
| Deep Space | 深空底色 | RGB (0.034, 0.045, 0.086) |
| Blue Nebula | 蓝色云雾 | RGB (0.15, 0.24, 0.45) |
| Violet Nebula | 紫色云雾 | RGB (0.26, 0.15, 0.4) |
| Starlight | 星光颜色 | RGB (0.68, 0.8, 1) |
| Nebula Strength | 星云强度 | 1.15 |
| Star Brightness | 星点亮度 | 0.65 |
| Star Density | 星点密度 | 0.0035 |
| Background Exposure | 仅背景曝光 | 1 |
| Rotation | 星空水平旋转 | 0° |

- Unity 脚本与 Shader 编译通过；Shader 无编译诊断，Console 零错误。[相机 PlayMode 结果](V0.10.1Validation/PlayMode.json) **5/5 通过**，覆盖七关背景绑定、全局天空盒保持、作者试玩/重开、V 键和 72 组环绕配置。规则层未改动，本轮未重复运行其 EditMode 回归。
- 已目视检查 [1080p 第三人称](V0.10.1Validation/ThirdPerson1080.png)、[720p 第三人称](V0.10.1Validation/ThirdPerson720.png)、[1080p 俯视](V0.10.1Validation/TopDown1080.png)及[反向低俯角](V0.10.1Validation/ReverseOrbit.png)。无粉色材质或可见接缝，背景不遮挡平台，首关同机位跟随距离仍为 4.8 m。720p 与反向图为不含 HUD 的直接相机渲染，另外两张含 HUD。
- 显式以 Bootstrap 场景完成 Windows x64 非开发构建，**零错误/零警告**；产物为 `Builds/V0.10.1/Windows/Robot Sokoban.exe`。BuildReport 确认新材质（324 B）与 Shader（6888 B）实际打包。本轮未启动独立 Player，画面证据来自 Editor。
- 81 个受保护的作者/现场草稿、关卡/解法、场景及 Editor 设置文件哈希未变，包括原有未跟踪的 `test111.json` 及 `.meta`。全局天空盒仍为原内置资源，环境光仍为 Flat / intensity 1；资源引用、文档链接和差异检查通过。
