## 目标与范围

- 制作一页英文 PowerPoint，讲述本周在 Michael 老师的 GSND 6000 课程中第一次学习 rigging，并通过 Blender + MCP 研究实践，为 game jam 小游戏机器人主角制作简单动画。
- 在空旷的临时测试场景中录制现有机器人的 Idle、Move、Push 动作，生成并嵌入循环 GIF。保持英文文案简洁、版式平整，不加装饰。
- 交付文件放在 `Docs/Art/GSND6000/`；构建、逐帧录制与检查临时文件放在忽略目录 `.utmp/GSND6000/`。
- 保留现有未提交资产、场景和配置修改。不改机器人源文件、正式关卡、动画剪辑、游戏规则、Unity 版本或依赖，不发布。
- 课程学习经历使用用户提供的信息；项目实践准确描述为机械层级动画，不将其宣称为已完成柔性蒙皮或人形骨架。

## 验收计划

1. 核对机器人现有动作与项目资产。录制前验证 Unity 项目路径和 Editor 就绪状态，使用独立临时预览场景并清理。
2. 查看各段 GIF 的代表帧与播放效果，确认动作、构图、循环及帧数。
3. 检查 PowerPoint 只有一页，文字可编辑、全英文、内容准确；嵌入三段实际 GIF。
4. 渲染并检查最终幻灯片，验证 PPTX 包结构、字体、几何布局与动画媒体完整性。
5. 检查文档链接、差异及工作区状态，只提交本次材料和版本记录。
