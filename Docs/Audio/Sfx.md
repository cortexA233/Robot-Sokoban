# 基础音效（v0.7.0 提前子项）

音效素材由本仓库 [GenerateSfx.py](../../Tools/GenerateSfx.py) 使用数学波形与固定种子噪声原创生成，没有第三方采样、下载素材或额外授权依赖，可随项目分发。重新生成：在仓库根目录运行 `python Tools/GenerateSfx.py`；保留已有 `.meta` 和 GUID。

## 素材与触发

全部位于 `Assets/Resources/audio/sfx/`，资源键为 `audio/sfx/<名称>`。44.1 kHz、16-bit、单声道 WAV；Unity 使用 PCM、Decompress On Load、预加载，关闭归一化与后台载入。总 WAV 文件约 178 KiB。声音使用 2D 播放，双视角混音一致。

| 名称 | 时长（秒） | 音色 / 触发 |
| --- | --- | --- |
| Move | 0.090 | 低音轻触 / 接受普通移动 |
| Push | 0.180 | 低频机械接触 / 推动动画接触时点 |
| Blocked | 0.140 | 短降音 / 规则拒绝移动 |
| Land | 0.190 | 低频落位 / 推动或整段滑行的最后落点 |
| PowerOn | 0.320 | 上升电子音 / 插槽从断电变为通电 |
| PowerOff | 0.280 | 下降电子音 / 插槽从通电变为断电 |
| Complete | 0.800 | 三音上行 / 完成动作的表现播放结束 |
| Click | 0.055 | 轻电子点击 / 玩家 UI 按钮和选关行确认 |

不对悬停和默认焦点播放声音。开发 GM 面板不在玩家 UI 点击音范围；同一插槽带动多个门只发一次供电声音，门占据保开不冒充电源变化。

## 生命周期与混音

`LevelRunner` 持有 `GameAudio`，六个动作声部加一个独立 UI 声部，所有源音量 0.65，继续受现有 `AudioListener.volume` 主音量控制。合成波形上限 0.42；淡入和淡出避免端点跳变。

受阻最短间隔 450 ms，普通同类事件 90 ms，点击 40 ms；供电按每个表现 microstep 的插槽状态差异聚合，同类变化不按门/来源数叠播。固定声部数限制极端事件密度；最旧声部在超额时被替换。

`CommandPresenter` 在动画接触、供电切换、最后落位和播放完成时触发声音；规则解析不播放音频。取消统一清理动作声部并使旧动画回调失效。暂停/导航遮罩/现场编辑/动画调试暂停停止动作声音，保留 UI 点击；恢复不重播已经发生的接触音，仅继续未来事件。初始装载、撤销、重开和 GM 状态恢复不重播供电/完成声音。退出会话销毁所有声部；主菜单与关卡分别启用对应监听器。
